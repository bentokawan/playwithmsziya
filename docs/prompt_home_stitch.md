# Prompt Stitch (Google) - Halaman Home "Play with Ms Ziya"

Gunakan instruksi terstruktur dan detail di bawah ini ke dalam **Stitch (stitch.google)** untuk men-generate desain UI halaman Home.

---

```markdown
Design a child-friendly, interactive, and playful web/tablet game Home screen for "Play with Ms Ziya" (Target Audience: Preschoolers aged 4–6 years old). 

The visual direction is inspired by cheerful early childhood learning apps (clean, soft 3D-feel buttons, chunky outlines, rounded geometry, vibrant pastel/bright tones, big cards, and star progression systems), but adapted for a dedicated widescreen/landscape layout (1280x720 canvas ratio, touch-friendly, high legibility).

### 1. Visual Style, Atmosphere & Guidelines
- **Art Direction:** Chunky flat vector style with solid navy bold outlines (border-width: 4px–6px), high-contrast elements, highly rounded pill/capsule corners (border-radius: 24px–32px), playful bounce shadows (hard offset dropshadow 6px–8px with zero blur for buttons).
- **Mood:** Cheerful, warm, welcoming, stress-free ("always encouraging", zero punitive elements).
- **Background:** Bright sunny warm yellow background (`#FFC62E`) overlaid with subtle, giant translucent watermarked floating decorative glyphs and letters: ('A', 'B', '1', '2', and Arabic hijaiyyah 'ا', 'ب') alongside soft white sparkles and playful confetti circles.
- **Typography:** 
  - Primary Display/Headings: Chunky rounded typography (like Fredoka / Baloo 2), thick stroke, friendly bubbly letterforms.
  - Body/Labels: Nunito (semi-bold/bold), clean, ultra-readable for kids.

### 2. Layout Structure (Landscape 1280 x 720 / Responsive Tablet Canvas)

#### Top Navigation Bar (Header - Fixed corners & clear margins):
- **Top-Left Corner:**
  - Original Friendly Mascot avatar: "Ms Ziya" (a cheerful, welcoming original character/guide) with a cute speech bubble saying *"Ayo main!"* / *"Let's Play!"*.
  - App Title badge beside it: "Play with Ms Ziya" rendered in bouncy colorful letters with navy outlines.
- **Top-Right Corner (Fixed Utility Buttons - Circle buttons min 64px–72px, bold icon, tactile 3D bottom shadow):**
  - Language toggle button 🌐 (Indonesian flag 🇮🇩 / English 🇬🇧 badge, protected by a mini lock/parental indicator).
  - Fullscreen toggle button ⛶ (Pill/circle with expand arrows).
  - Sound/Music audio toggle 🔊 (Bright circle with speaker wave icon).

#### Central Content Area: Game Category Hub (Horizontal scrolling / Organized Grid of Chunky Cards):
Present the 4 main skill categories as organized, color-coded sections/lanes or a lively card deck. Each game card is tactile, rounded (approx 280x180px or chunky squircle), creamy white/light pastel card body with colored headers, big 3D embossed icon tile on the left, bold game title, and a 3-star rating indicator (`★ ★ ☆` filled in gold with navy outlines, unfilled in pale lavender).

1. **Angka / Numbers Hub (Sky Blue Theme - `#4DB8FF`):**
   - Game 1: **"Ayo Berhitung"** (Counting to 20): Icon showing colorful fruits/balloons jumping into a cute woven basket, displaying `★★★`.
   - Game 2: **"Menulis Angka"** (Number Tracing): Icon showing a giant playful number '5' with dashed guide dots and a finger tracing path, displaying `★★☆`.

2. **Huruf / Letters Hub (Coral Red Theme - `#FF6B6B`):**
   - Game 1: **"Susun Kata"** (Spelling/Word Builder): Icon showing letter blocks spelling a word below a cute picture of an apple/ball.
   - Game 2: **"Bunyi Awal"** (First Sounds): Icon of an ear listening to a singing bird/phonics sound.
   - Game 3: **"Menulis Huruf"** (Letter Tracing): Icon of a chunky letter 'A' with multi-color stroke trails.

3. **Hijaiyyah Hub (Fresh Tosca Green Theme - `#3DE6CF`):**
   - Game 1: **"Dengar & Temukan"** (Listen & Find Hijaiyyah): Icon of large hijaiyyah letter 'ب' inside a bright tosca card with a sound speaker icon.
   - Game 2: **"Tebalkan Hijaiyyah"** (Trace Hijaiyyah): Icon of a dashed hijaiyyah letter 'ج' with a glowing start-point beacon and tracing sparkles.

4. **Ingat & Main / Memory & Mini-Games Hub (Playful Lavender Theme - `#9B8CFF`):**
   - Game 1: **"Kartu Kembar"** (Memory Flip Cards): Icon showing 2 flipped cards with matching smiling stars.
   - Game 2: **"Petualangan Labirin"** (Maze Adventure): Icon showing a colorful mini maze path leading to a yummy cupcake.

#### Bottom Status Bar (Floating Pill / Sticky Dock):
- A clean, pill-shaped floating panel at the bottom center or bottom left (`#FFF6E5` warm cream background, navy outline):
  - Left: Child's chosen avatar icon (e.g. smiling playful character) and nickname (e.g. "Adik Bintang").
  - Center/Right: Total earned rewards widget with a giant shiny golden star `⭐` and a bold counter badge: *"12 Bintang"*.
  - Mode Switch Pill: Quick toggle or indicator for `[ 1 Pemain 👤 ]` vs `[ 2 Pemain / Duel 👥 ]`.
  - Subtle Parent Gate button at the bottom right corner with a gear icon and small padlock ("Area Orang Tua / Parents").

### 3. Color Palette & Component Specs
- Background: `#FFC62E` (Sun Yellow)
- Surface/Cards: `#FFF6E5` (Warm Cream White) with `#1F2A5C` (Deep Navy) borders
- Category Colors:
  - Numbers: `#4DB8FF`
  - Letters: `#FF6B6B`
  - Hijaiyyah: `#3DE6CF`
  - Memory: `#9B8CFF`
- Feedback & Rewards: Filled Gold Star `#FFD200`, Success Mint `#3CCB7F`, Warm Orange `#FF9F43`
- Accessibility & UX: Minimum tap target size 64x64px, generous 16px–24px gaps between cards, zero clutter, high contrast (≥ 4.5:1), zero stressful elements.
```
