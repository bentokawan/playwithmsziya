Bahasa Indonesia+ inggris -> jadi bisa pilih bahasa
Usia : 4-6 tahun
Keterampilan: 
- angka + menulis angka
- huruf + menulis angka
- daya ingat
- hijaiyyah + menulis hijaiyyah

=========================

Level : 

Mudah, sedang, menantang
- Ada tulisan klik mulai atau start dan tombol tanda panah
- hijaiyyah : 
  - Dengarkan bunyi dan temukan hurufnya
  - menulis hijaiyyah : tebalkan huruf Hijaiyah dengan jarimu

- Angka : 
  - ayo berhitung, menghitung benda satu persatu, dan mencocokan benda dengan angkanya 1-20
  - menulis angka dengan jari

- Huruf : 
  - menyusun kata sesuai urutan untuk mengejanya
  - mendengar bunyi awal sebuah kata dan mencocokan dengan hurufnya
  - menulis huruf dengan jari 

- Game dan daya ingat :
  - kartu kembar ketuk 2 kartu untuk membaliknya temukan pasangan yang sama 
  - petualangan labirin : temukan melewati labirin menuju makanan enak


Fiturnya ada untuk di mainkan berdua nya juga
Jadi single dan sama apa duel atau 2 player
Ada tombol di pojok kanan atas untuk membesarkan layar ke full screen
